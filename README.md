# Дежурный LSCSD · Boston 1.3

Личная программа для сотрудников LSCSD на Majestic RP Boston: законка, ситуации, калькулятор и процессуальные таймеры.

Готовая программа распространяется архивом BostonDuty-Windows.zip в разделе Releases репозитория. Распакуй всю папку BostonDuty и открой BostonDuty.exe. Интернет и Node.js для готовой программы не нужны. Исходники в разделе Code не содержат готовый exe.

F6 показывает и скрывает маленькое окно 420×680 поверх других окон. Крестик скрывает программу, таймер продолжает работать. Полностью выйти можно через значок в трее → «Выйти». Повторный запуск показывает уже работающую программу. В настройках можно выбрать другую клавишу, прозрачность и обычное большое окно. В игре используй оконный режим без рамки для отображения окна поверх игры.

В программе есть поиск по 774 нормам Boston, избранное, ситуации, справочник задержания без ввода человека, памятка по возражениям адвоката, процессуальные таймеры и калькулятор с шаблонами команд.

Калькулятор показывает штраф по одной статье и сумму диапазонов по нескольким статьям с разбивкой УК/АК/ДК. УК 17.6 ч.1: $20 000–$60 000. УК 17.6 ч.1 + УК 17.3 ч.1: справочная сумма $40 000–$110 000. Если штрафа нет, отображается «Не указан».

Сумма диапазонов УК/ДК — справочная арифметика, а не автоматически назначаемый штраф. Согласно УК 5.2 ч.4 обычное наказание по совокупности ограничено наиболее строгой статьёй; отдельные исключения требуют проверки нормы. Штрафы АК складываются согласно АК 1.11. Калькулятор отдельно проверяет стадии и юрисдикцию, не складывает сроки УК автоматически.

ИИ-помощник, API и запись звука удалены. Дела, настройки, избранное и подборка хранятся локально; резервную копию можно экспортировать в настройках.

Снимок законов: https://majesticrules.fun/laws/boston/ . Полные источники доступны в каждой норме. Сверяй актуальную редакцию перед применением.

## Запуск из исходников

Установи Node.js 22 или новее и выполни в папке проекта:

```powershell
npm ci
npm start
```

Проверки: `npm test`. Просмотр интерфейса в браузере: `npm run web`, затем открой http://127.0.0.1:4317. Закрепление окна и глобальная клавиша работают в настольной программе.

## Сборка для Windows

```powershell
npm run portable
Compress-Archive -LiteralPath release/BostonDuty -DestinationPath BostonDuty-Windows.zip -Force
```

Результат: `release/BostonDuty/BostonDuty.exe`. Переносить нужно всю папку, а архив выкладывать как вложение GitHub Release. Зависимости, готовые сборки, тестовые профили и локальные настройки исключены из Git.

Исходный проект использует Electron 42; первая локальная переносная сборка 1.3 собрана на доступном runtime Electron 28.3.3. Новая сборка использует установленный Electron. Версия runtime записана в BUILD-INFO.json.
